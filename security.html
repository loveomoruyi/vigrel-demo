Privacy architecture

The model is local. So is the argument.

Most assistants promise not to store your data. Vigrel removes the server that could. This page describes the architecture, not the policy — and it is specific about the few moments when bytes do leave.

On the machine

What runs where

Inference

llama-server bound to 127.0.0.1. The weights are a file on your disk. There is no inference endpoint to call and no API key to leak.

Speech

Whisper transcribes locally; Kokoro synthesises locally. Audio is processed in memory and discarded — there is no recording folder.

Memory

A SQLite file in ~/.jarvis. Facts, sessions and projects live there. Inspect it, export it, or delete it — the app does not hold a second copy anywhere.

Loopback only. The engine listens on 127.0.0.1:8765, the brain on :28090, audio on :28120. Nothing binds to a public interface, so another machine on your network cannot reach them either.

Egress

The complete list of what can leave

Everything here is either initiated by you or disabled by configuration. There is no background sync, no telemetry SDK, no crash uploader, no analytics.

That is the whole list. If a future feature needs the network, it will appear in this table before it ships.

Cloud add-on

Stateless compute, not a data store

The optional cloud tier moves the arithmetic, not the archive. A request carries the prompt window needed for that turn. The server has no conversation table, no prompt log and no training pipeline; it returns tokens and forgets the request.

  • Memory and history stay on the device.
  • Only the current turn's prompt is transmitted.
  • No account identity is required to process a request.
  • If the network is down, it falls back to the local model.

Later

Encrypted sync, when multi-device demands it

If sync ships, it ships as ciphertext: a key derived from your passphrase on the device, AES-256-GCM before upload, and an opaque blob on the server. We would hold a file we cannot read — and deletion would be crypto-shredding rather than a row delete.

It is not built yet. It is described here so the architecture is not a surprise later.

Honest limits

What local does not fix

It runs with your privileges

Point it at a script and it can run the script. Approvals are real approvals. Keep backups, and do not hand it a shell you would not hand a colleague.

The model can be wrong

Confidently. Arithmetic, file contents and live data are answered by tools rather than the model for exactly that reason — but prose can still be mistaken.

Your disk is the boundary

Full-disk encryption, a locked screen and a separate account matter more here than they do with a cloud assistant, because the data is genuinely on your drive.

One more, specific to this machine class. A large model at the edge of a machine's memory can starve the audio stack of wired memory; macOS then refuses to start audio streams and the app falls back to the system voice. That is a hardware ceiling, not a privacy flaw — and it is why the tier table is conservative.
