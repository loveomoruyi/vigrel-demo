Features

Everything runs here.

Six capabilities, each exercised on a real machine and a real conversation. No feature below requires an account, an API key, or a network connection.

01 · Voice

A conversation with a beginning, a middle and an end.

Press the microphone, speak naturally, and Vigrel answers in a British butler's register. It holds the thread across turns, waits for you to finish, and stops the moment you ask it to.

  • Local transcription — audio is processed on the machine and discarded
  • End-of-speech detection at 700 ms rather than a fixed timer
  • Echo guard: while it speaks, its own input is ducked so it cannot answer itself
  • The toggle means what it says — off is silent, not "quietly listening"

02 · Memory

It remembers the work, not just the words.

Facts you state, projects you start, decisions you make and the exchanges themselves are written to a local SQLite database. Each spoken turn carries the recent conversation with it, so "what did we decide about the firewall?" resolves without you repeating yourself.

  • Durable facts, session state and project history in one file
  • Inspect it with any SQLite browser; delete it with one command
  • Never inferred from background chatter — names only when you give them

03 · Builds

It writes files, opens them, and checks the result.

Ask for a multi-page site, a document or a small tool. Vigrel plans the structure, writes the files to disk, opens the result and verifies it — then tells you where it is. A build that fails says so instead of claiming success.

  • Multi-page output with working navigation, not a single landing page
  • Verification step before it reports back
  • Runs in a queue: start a build, keep talking

04 · Vision

Look at my screen — only when asked.

One keystroke captures the current display, describes what matters, and answers questions about it. The frame is processed locally and never stored: there is no screenshot folder and no upload path.

  • Invoked explicitly, never in the background
  • Useful for error dialogs, dashboards and configuration screens
  • Available on tiers with the vision projection installed

What it is

  • A private operator with hands on your machine.
  • A conversationalist with memory and a consistent voice.
  • A builder that writes, verifies and opens real files.
  • A tool that works with the network cable pulled out.

What it is not

  • Not a browser tab, and not a wrapper around someone else's API.
  • Not an always-on listener.
  • Not a chatbot with a personality bolted on.
  • Not a cloud service with a desktop icon.
