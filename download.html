Before you run it

Is this safe to install?

Fair question — it is an unsigned app from a small independent project, which is exactly the pattern you should be suspicious of. Here is the honest accounting, and how to check it yourself.

What it asks for

  • Microphone access — only when you switch voice on.
  • Disk space — 1–23 GB, for the model and voice pack you choose in setup.
  • A local server on 127.0.0.1 — reachable only from your own machine.

What it never does

  • No telemetry, no analytics, no account required for the trial.
  • Your conversations, memory and files are never uploaded.
  • The only network access is the one-time downloads you start yourself in setup.

The test that settles it

Finish setup, then turn off Wi-Fi (or unplug the cable) and keep talking to it. It keeps working — the model runs on your machine, not someone else's server. You can also watch it in Task Manager (Windows) or Activity Monitor (macOS): after setup it talks only to 127.0.0.1.

Why your computer will warn you

This build is not signed with a commercial code-signing certificate yet — that is a paid, registered-company milestone and the next thing on the list. So: Windows will show “Windows protected your PC” → More info → Run anyway. macOS 15+ shows “Apple cannot check it” → System Settings → Privacy & Security → Open Anyway. That warning is about the app's identity, not about detected malware — and you do not have to trust our word either: verify the SHA-256 above with one command before running anything.

Extra cautious? Run it in a disposable Windows PC

Windows Pro and Enterprise include Windows Sandbox — a throwaway Windows that vanishes when you close its window. Download our ready-made config (vigrel-sandbox.wsb, 1 KB), keep it next to the installer in your Downloads folder, and double-click it. A fresh Windows opens with your Downloads folder attached read-only and the microphone shared through, so voice works. Install Vigrel in there, try everything, then close the window — nothing it did survives. Notes: Windows Home does not include Sandbox (use the offline test above instead); the model re-downloads on each sandbox session; virtualization must be enabled in your PC's firmware.

Vigrel is built by one independent developer at Vigrel Systems, not a company you have heard of — which is exactly why it deserves this scrutiny. If you would rather not run a beta, that is a completely reasonable call.
