Capabilities

What Vigrel actually does

Six things, done properly, on hardware you already own.

Full feature tour

Spoken dialogue

Hold a conversation with a mic toggle that behaves: on means listening, off means silent. Utterances are transcribed locally and answered in about three seconds.

Long-term memory

Facts, projects and prior exchanges live in a local database. It knows what you were working on last week because it wrote it down, not because a provider kept it.

Real builds

Multi-page sites, documents and small applications — written to disk, verified, opened. Not a code block in a chat window.

Screen vision

On request only: capture the screen, describe what matters, answer questions about what is on it. Nothing is recorded or uploaded.

Skill packs

Load a pack — network operations, document drafting, research — and Vigrel gains the vocabulary, tools and guardrails for that job.

Offline by default

Air-gapped is a supported configuration, not an apology. Pull the network cable and every core capability still works.

Voice

It speaks like a butler, and it waits its turn.

The microphone is an explicit toggle, not an always-on listener. While Vigrel is speaking it ducks its own input so it never answers itself, then resumes listening the moment it finishes.

  • Local transcription — audio never leaves the machine
  • End-of-speech detection at 700 ms, not a fixed timer
  • Interruptible: switch the mic off and it stops talking

Memory

Continuity without a data lake.

Vigrel keeps its own notes: who you are, what you asked for, what it built, which decisions you made. The store is a SQLite file in your home directory — inspectable, exportable, and deletable with one command.

  • Session state, durable facts and project history in one local file
  • Recent exchanges carried into each spoken turn for real continuity
  • Optional encrypted sync later — your key, unreadable to us
